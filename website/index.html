What it does

Clean and enrich contact data without leaving your AI agent

The YourICP MCP server exposes the YourICP enrichment API as Model Context Protocol tools. Any MCP-compatible assistant can call them to turn raw emails and LinkedIn URLs into verified, enriched B2B records.

Data cleaning

Verify and standardize B2B contact records — deduplicate, validate, and correct stale CRM fields at the source.

Contact enrichment

Enrich by email address or LinkedIn URL. Return firmographic and role data ready to write back to your CRM.

Built for agents

Standard MCP stdio transport. Works with Claude Desktop, Cursor, ChatGPT, and any MCP-compatible client.

Tools

Three tools, zero boilerplate

ToolDescription
set_tokenSet a YourICP API token for the session
submit_lookupEnrich contacts by email or LinkedIn URL (returns a job ID)
check_lookupPoll the enrichment result for a job ID
Quick start

Run it with one command

No clone, no global install. You need Node.js 18+ and a YourICP API token from app.youricp.com.

YOURICP_API_TOKEN=your_token_here npx @youricp/mcp

Connect to Claude Desktop

Add this to your claude_desktop_config.json, then restart Claude Desktop:

{
  "mcpServers": {
    "youricp": {
      "command": "npx",
      "args": ["-y", "@youricp/mcp"],
      "env": { "YOURICP_API_TOKEN": "your_token_here" }
    }
  }
}

How it works

From raw contact to verified record

Connect the server

Add YourICP to your MCP client with the config above and your API token.

Ask your agent to enrich

"Enrich these five emails and clean the results" — the agent calls submit_lookup.

Get verified data back

The agent polls check_lookup and returns clean, enriched records ready for your CRM.
